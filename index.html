How the model works

01 · Physics baseline

Linear regression uses a physics-inspired feature based on proton number and alpha-decay energy, plus neutron odd/even information, to estimate log half-life.

02 · Machine-learning correction

RBF-SVR learns patterns in the baseline's remaining errors (residuals) from the three isotope features and adds a correction.

SVR settings: C = 10, epsilon = 0.01, gamma = 0.01. This phase focuses on developing and demonstrating the model with the four training elements.
